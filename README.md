# fist-game / 卫月放置

一个 Melvor Idle 风格的放置游戏。**当前目标：先做成一个能在本地跑起来、能玩的小游戏。**

> 最终愿望是让它以 Dalamud 插件的形式跑在 FFXIV 里，但那是后面的事。
> 现在先把"游戏本身"和"写代码这件事"搞明白。

## 当前进度

- [x] 项目初始化
- [x] 第一个可运行版本：伐木技能（自动产出 + 手动砍 + 升级）
- [ ] 存档 / 读档
- [ ] 第二个技能
- [ ] 用木材买升级

## 怎么运行

需要 .NET 10 SDK。在 `Game` 目录下：

```
dotnet run
```

## 怎么玩

| 按键 | 作用 |
|---|---|
| `1` | 手动砍一刀 |
| `Q` | 退出 |

什么都不按，木材也会自己涨（这就是"放置"）。

## 目录

```
fist-game/
└── Game/
    ├── Program.cs          界面：画画面、收按键
    └── Core/IdleGame.cs    规则：只算数字，不管显示
```

把"规则"和"界面"分开放，是为了以后换界面（窗口、网页、甚至游戏插件）时，规则那部分一行都不用改。
