# fist-game / 卫月放置

一个 Melvor Idle 风格的放置游戏，以 **Dalamud 插件** 的形式运行在最终幻想 XIV 中。

> 当前状态：项目初始化（P0）。还没有可运行代码。

## 目标

- 纯放置玩法：技能 → 资源 → 消耗 → 高阶技能 的闭环
- 离线收益结算（按时间差 + 上限）
- 数据驱动内容（配方 / 怪物 / 掉落 走 JSON，代码只做解释器）
- 完全独立运行：不读游戏内存、不参与战斗、不产生任何游戏内优势

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 内核 | C# 类库 | 零 Dalamud 依赖，可单测、可复用到桌面/网页版 |
| 外壳 | Dalamud 插件 + ImGui | 当前 API Level 15 |
| 存档 | 自管 JSON（版本号 + 迁移） | 不依赖数据库 |

## 开发环境

- Windows
- .NET SDK（版本需与 Dalamud 当前 API 15 的目标框架一致）
- 本地调试：编译产物放入 `%APPDATA%\XIVLauncher\devPlugins\<InternalName>\`
